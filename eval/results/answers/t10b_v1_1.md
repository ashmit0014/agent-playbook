**What it does:** it reads your bank export and checks the bank's running balance row by row. It then writes a semicolon-separated file with dates as DD.MM.YYYY and amounts with the bank's sign kept. When it finishes, it prints the number of rows, the total and the opening and closing balance, so you can compare them with your bank statement.

**Fails loudly, leaving no output file:**
- the input isn't in the expected format, or the running balance doesn't add up;
- an amount would need rounding;
- the output file already exists (`--force` overrides this, but it will never overwrite the input);
- the file it just wrote doesn't match what it read when it re-checks it row by row.
