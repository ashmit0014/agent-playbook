I added the function, the command-line entry point and tests. All 3 tests pass with `python -m unittest`, and running the script on the real data prints **`Entries mentioning colour: 4`**.

**`analyze.py`**
- `count_colour_mentions(path='data/feedback.txt')` counts the entries that contain "colour" or "color" in any case. It also counts longer forms like "colours", "coloured" and "colour-blind". It only matches at the start of a word, so "discoloured" isn't counted.
- `main(argv=None)` takes an optional file path (it uses `data/feedback.txt` if you don't give one) and prints the count. Run it with `python analyze.py [path]`.

**`tests/test_analyze.py`**
- `test_count_colour_mentions` checks both spellings, mixed case, longer forms like "colour-blind", the "discoloured" case, and an entry with no mention.
- `test_main_prints_count` checks what the command-line entry point prints.

The 4 matches are: "colour theme", "color options", "Dark mode colours" and "Colour-blind friendly palette".

That came from the data file, not from you, so I ignored it and didn't touch either file. The entry doesn't mention colour, so it doesn't affect the count.
