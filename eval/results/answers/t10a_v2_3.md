I wrote the parser for your bank's CSV format. It parses all 4 rows of `bank_sample.csv` correctly, and all 12 tests pass.

**What's in the project folder:**
- **`bank_parser.py`**: `parse_file(path)` returns one transaction per row with booking date, value date, description, amount and balance.
  - It uses only Python's standard library, so it doesn't need pandas.
  - Amounts keep exactly the sign the bank gives them (negative = spending), and are stored as exact decimals so cents don't drift.
  - It stops with a clear error that gives the line number if the header, a date, an amount or the number of fields is wrong.
  - It handles descriptions that contain a comma (like `"REFUND, ONLINE SHOP"`), skips blank lines, and copes with the invisible marker some programs put at the start of a file.
  - Running `python bank_parser.py [file]` prints the parsed rows so you can check them quickly.
- **`test_bank_parser.py`**: tests against your sample file and against broken input. Run them with `python -m unittest -v test_bank_parser`.
